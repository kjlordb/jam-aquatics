# JAM Aquatics

A premium web application for **JAM Aquatics**, featuring a dramatic Ukiyo-e inspired Samurai and Arowana theme. Built with Vanilla JavaScript and Vite.

## Preview

The application features:
- A responsive, glassmorphism UI.
- Autoplaying background video Hero section.
- Premium fish showcase with CSS animations.
- Dark mode oceanic aesthetic.

## Local Development

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/kjlordb/jam-aquatics.git
   cd jam-aquatics
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Production Build

To create a production-ready build:

```bash
npm run build
```
The optimized files will be generated in the `dist` directory.
